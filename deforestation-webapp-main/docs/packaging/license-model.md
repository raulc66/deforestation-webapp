# License model

`LICENSE` at the package root is a **draft for counsel**. It is not legal advice.

| Tier | Intended grant |
|------|----------------|
| **Developer** | Evaluation and development, non-production, no redistribution |
| **Commercial** | Production internal use, modification allowed, no redistribution, no resale as a competing ForestWatch source package |
| **Agency / Customization** | Named-client deployments and white-label under the license; copyright stays with the original owner unless a separate assignment exists |
| **Exclusive acquisition** | Negotiated assignment of **original** ForestWatch IP and repository transfer; excludes third-party libraries, datasets, trademarks, and provider rights |

Third-party dependencies and datasets stay under their own terms (`NOTICE`). Stripe accounts and API keys belong to the licensee. Copernicus/NASA/GFW/EEA/EFFIS attribution still applies when those materials or live feeds are used.

A standard MIT/Apache grant of ForestWatch original code would allow unconstrained redistribution and would undermine a source-code sale. This package does not use an OSI open-source license for original ForestWatch code.
