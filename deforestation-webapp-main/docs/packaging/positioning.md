# Positioning

## Primary

**Multi-tenant geospatial intelligence platform** with a **forest-monitoring reference application**.

ForestWatch original source is licensed commercially (see `LICENSE`). The forestry implementation and Romania dataset/demo show how a vertical sits on the engine. They are not a claim that ForestWatch is only Romanian illegal-logging software.

## Secondary language (supported)

Use only where they describe actual code:

- geospatial intelligence platform
- geospatial monitoring foundation
- environmental monitoring **reference** implementation
- GIS intelligence platform
- source-available geospatial platform

## Rejected claims

Do not advertise:

- illegal logging detection product, or legal proof of illegal activity
- AI satellite platform / satellite processing engine
- Romanian government replacement
- hosted Forest Intelligence SaaS subscription (this zip is source, not a hosted service)
- generic “AI-powered everything”
- live all-provider data as guaranteed
- Stripe as a validated production billing system
- placeholder modules (`ai_predictions`, `satellite`, `scraping`) as shipped features

## What is production-oriented vs reference

**Production-oriented in this codebase (still requires operator hardening):** authentication, organizations, AOIs, intelligence cycle, Command Center, investigations, customer alerts, entitlements, reports, in-process scheduler.

**Reference / optional:** Romania seed and demo catalog, simplified CORINE GeoJSON, FIRMS mock, synthetic provider, trial UX, Stripe module (disabled, unvalidated).

## Buyer personas

Developers and GIS/environmental startups, agencies wanting private deploy, researchers, companies buying a foundation, exclusive IP acquisition of **original** ForestWatch code (third-party rights excluded).
